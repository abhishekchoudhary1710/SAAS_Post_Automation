# Background music for reels

Drop one or more `.mp3` files in this folder and every reel mixes one of them in at low
volume under the voice-over. With the folder empty, reels are voice only, which is fine.

Use tracks you are allowed to use commercially. Free sources:

- YouTube Audio Library (studio.youtube.com, Audio Library tab): free for any use, no attribution needed.
- Pixabay Music (pixabay.com/music): free, no attribution needed.

Pick calm, low-energy tracks (lo-fi, soft piano, ambient). Keep files under 5 MB.
